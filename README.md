# 💾 Projeto Backup System — Visual Basic 6

Sistema desenvolvido por **Fábio Alexandre Riqueto**, originalmente no ano de **2003**, para realização automatizada de cópias de segurança.

O projeto é disponibilizado neste repositório como parte do meu portfólio profissional, preservando uma solução desenvolvida durante minha trajetória com sistemas empresariais, automação e gerenciamento de dados.

## 📌 Sobre o projeto

O **Projeto Backup System** foi desenvolvido com o objetivo de realizar cópias de segurança de dados de forma programada, permitindo definir **locais e horários específicos** para a execução dos backups.

A solução foi criada para auxiliar na rotina de proteção dos dados e reduzir a necessidade de realização manual das cópias de segurança.

Por se tratar de um sistema desenvolvido originalmente em **2003**, sua implementação utiliza tecnologias compatíveis com o período de desenvolvimento.

## ⚙️ Tecnologias utilizadas

- Visual Basic 6
- Microsoft Access
- Windows

## 💾 Funcionalidade principal

### Cópias de segurança

O sistema foi desenvolvido para realizar cópias de segurança de acordo com parâmetros previamente configurados, considerando:

- Local de origem dos dados;
- Local de destino da cópia;
- Horários definidos para execução;
- Rotina automatizada de backup.

A configuração adequada do ambiente é necessária para o funcionamento da aplicação.

## 🔄 Automação

Uma das características do projeto é a utilização de uma aplicação para automatizar uma tarefa operacional que normalmente dependeria da intervenção manual do usuário.

A solução permite estabelecer uma rotina de cópias de segurança de acordo com as necessidades do ambiente em que foi instalada.
